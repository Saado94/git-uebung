# Git-Notizen

Git ist ein Versionsverwaltungssystem. Es hilft dabei, Änderungen an Dateien zu speichern und nachzuverfolgen.


## Wozu ist Versionsverwaltung nützlich?

Versionsverwaltung hilft dabei, Änderungen an Dateien zu speichern und nachzuvollziehen. Mit Git kann ich sehen, was ich geändert habe, zu früheren Versionen zurückkehren und verschiedene Entwicklungsstände vergleichen. Dadurch gehen wichtige Informationen nicht so leicht verloren.
